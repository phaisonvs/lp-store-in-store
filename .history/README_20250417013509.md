# Seja um Franqueado - ABC da Construção

## Sobre o Projeto

Página de captação para potenciais franqueados da ABC da Construção, com foco em:

- Apresentação do modelo de negócio
- Prova social com depoimentos
- Dados de performance da franquia

## Tecnologias Utilizadas

- HTML5 semântico
- CSS3 moderno com variáveis e animações
- JavaScript puro (Vanilla JS) para interações

## Como Executar Localmente

1. Clone este repositório
2. Abra o arquivo `local/index.html` em seu navegador
3. Para desenvolvimento, utilize o Live Server (extensão VS Code)

## Estrutura de Arquivos

- `local/index.html`: Página principal
- `local/style.css`: Estilos principais
- `local/script.js`: Lógica e interações
- `local/assets/`: Imagens e recursos
